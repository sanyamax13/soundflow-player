## Зачем (мотивация Alex)

Сейчас телефон видит компьютер, только когда оба в одной домашней Wi-Fi
сети. Alex хочет пользоваться программой (слушать весь каталог, Открытия,
Волну) когда его нет дома — то есть удалённо, через интернет, но
безопасно и без пробрасывания портов вручную.

## Предложенная архитектура (моя прикидка, ещё не подтверждена)

- **Компьютер (Go)**: Tailscale встраивается ПРЯМО В программу через
  `tsnet` (официальная Go-библиотека Tailscale) — отдельно ставить
  Tailscale не нужно. Подключение к сети Tailscale — через ключ-авторизацию
  (auth key), который Alex получает один раз в своём аккаунте Tailscale и
  вводит в программе (нужна кнопка в Настройках для этого).
- **Телефон (Flutter)**: готового чистого способа встроить Tailscale внутрь
  приложения нет (нет официального Flutter SDK). Предложение: НЕ встраивать,
  а поставить обычное официальное приложение Tailscale из Play Store —
  один раз войти в аккаунт, дальше оно само всё держит в фоне. Наше
  приложение при этом не меняется вообще — тот же экран «Адрес сервера» +
  то же подтверждение подключения (сделано сегодня), просто адрес будет
  вида 100.x.x.x (Tailscale) вместо 192.168.x.x (домашний Wi-Fi).
- Обсуждали вариант «код на компьютере — вводишь на телефоне» для
  сопряжения через Tailscale (Alex TG 09:12) — по факту сам Tailscale так
  не работает (у него single-account модель, не код между двумя
  устройствами) — если ставим обычное приложение Tailscale на телефон
  (см. выше), эта часть решается самим Tailscale, свой код изобретать не
  нужно.

**Обновление после интернет-исследования (24.09.2026, позже в тот же
день)**: нашёлся пакет `tailscale` на pub.dev (Dart/Flutter,
github.com/danReynolds/tailscale_dart) — оборачивает официальную Go
tsnet-библиотеку, даёт embedded Tailscale ПРЯМО в Flutter-приложении, БЕЗ
отдельной установки Tailscale на телефоне. Поддерживает Android (нужен API
31+, то есть Android 12+) и iOS. Важные оговорки: издатель на pub.dev
НЕ верифицирован (независимый разработчик, не сам Tailscale.com), версия
0.9.0 — ещё до 1.0, «минорные версии могут ломать API». То есть реально
существует способ встроить и на телефон тоже — но это более молодая,
менее проверенная вещь, чем встраивание в Go на компьютере (у tsnet для
Go — солидный статус, официальный, давно используется). Меняет мой более
ранний ответ Alex «на телефоне готового способа нет» — способ есть, но
с реальным риском незрелости.

1. **«Открытия»/«Волна» — главное**: скачивать песни оттуда удалённо,
   обновлять список удалённо (не ждать, пока Alex дома).
2. Лайки/дизлайки должны уходить на компьютер СРАЗУ (не после возврата

`/api/discover/undismiss` — cmd/soundflow/service.go) — проверить, не
нужны ли они и телефону тоже, прежде чем это станет проблемой при
удалённой работе.

## Решение принято (24.09.2026) — три мнения сошлись

Интернет + моё мнение + сторонний ИИ (ChatGPT/Gemini) все сошлись на одном:
- **Компьютер**: tsnet встроен прямо в Go-программу.
- **Телефон, первая версия**: обычное официальное приложение Tailscale
  (не пакет `tailscale_dart` 0.9 — слишком сырой для старта, вернуться к
  нему можно будет позже, когда ядро приложения будет готово).
- **«Вечно включённый сервер»**: специально переносить некуда не нужно,
  brain остаётся сервером — пока включён, телефон достаёт через Tailscale
  откуда угодно; выключен — как и сейчас, недоступен.

### Технические нюансы для tsnet на компьютере (от стороннего ИИ, важно не забыть при реализации)
1. **Обязательно задать `Dir`** в `tsnet.Server` — путь к постоянной папке
   на диске (например, `%LocalAppData%\SoundFlow\tailscale`). Без этого
   состояние живёт только в памяти, и Auth Key придётся вводить заново при
   КАЖДОМ перезапуске программы вместо одного раза.
2. **Истечение ключа**: обычные узлы Tailscale требуют переавторизации
   каждые ~180 дней — сервер может молча отвалиться от сети, Alex не
   заметит сразу.
3. **Решение п.2 — тег на Auth Key**: при создании ключа в админке
   Tailscale назначить тег (например `tag:media-server`) — у устройств с
   тегом (это «сервисы», не «люди») истечение ключа автоматически
   отключается.
4. **Ключ — секрет, не в код и не в git** (второй ответ ИИ, тот же день):
   `TS_AUTHKEY` — переменная окружения/защищённый секрет на диске
   компьютера, никогда не строкой в исходниках и тем более не в коммите.
   После первого входа tsnet сам сохраняет состояние (см. п.1, `Dir`) и
   дальше переподключается без ключа — вводить его повторно не нужно.
5. **Важно на будущее, если когда-нибудь решим встраивать Tailscale И в
   телефон (пакет `tailscale_dart`, вариант (б))**: НЕЛЬЗЯ зашивать
   постоянный Auth Key внутрь APK, который раздаётся другим людям — APK
   можно распаковать, ключ вытащат, и тогда кто угодно сможет добавить
   произвольное устройство в тайлнет Alex-а. Это ещё один довод (помимо
   незрелости пакета) в пользу варианта (а) для APK, который может
   попасть не только к Alex.

## Готово к реализации — чек-лист V1 (от стороннего ИИ, подробный ответ)

Все мнения сошлись (моё + 2 ответа ИИ) — план можно реализовывать.
`soundflow.exe` сам становится Tailscale-узлом (`tsnet.Server` прямо в
программе, БЕЗ отдельного tailscaled/прокси — штатный сценарий tsnet).

V1 чек-лист:
1. Отдельное имя узла для Go-программы (hostname в тайлнете).
2. Auth Key — только на компьютере (переменная окружения/секрет, см.
   нюансы выше — тег, `Dir`, не в git).
3. Постоянное состояние tsnet на диске (см. нюанс 1 выше).
4. Программа сама поднимает Tailscale-узел при своём обычном запуске
   (никакого отдельного шага руками, кроме ввода ключа один раз).
5. ACL в тайлнете (кто из устройств Alex-а имеет доступ — настраивается
   в самом аккаунте Tailscale, не в нашем коде).
6. Flutter (официальное приложение Tailscale на телефоне) знает только
   адрес/hostname сервера — обычная сеть с его стороны, никакой
   Tailscale-специфики в коде телефона не нужно.
7. Никакого проброса портов наружу — весь смысл Tailscale в том, чтобы
   этого не делать.

V2 (не сейчас, на будущее, если Alex сам решит вернуться): пакет
`tailscale_dart` внутрь Flutter, чтобы совсем убрать необходимость
ставить Tailscale на телефон отдельно — тогда SoundFlow полностью
самодостаточен. Условие переоценки — пакет дозреет до релиза (сейчас 0.9),
и то только для приложения, которым Alex пользуется САМ (не раздаёт
другим) — раздавать чужим людям APK с зашитым Tailscale-ключом нельзя
(см. нюанс 5 выше, ключ можно вытащить из APK).
