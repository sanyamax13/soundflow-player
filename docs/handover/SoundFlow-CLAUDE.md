# SoundFlow — инструкция для Claude (своя копия плеера)

Этот файл — для ИИ-помощника (Claude Code), который помогает владельцу этой копии SoundFlow.
Человеку — PDF «SoundFlow-инструкция». Здесь — как всё устроено, где что лежит и как чинить.

## Что это

SoundFlow — личный музыкальный плеер без подписок. Музыка лежит на Windows-компьютере владельца,
телефон Android играет её дома (Wi-Fi) и вне дома (через свой ВДС владельца).
Автор программы — другой человек (Alex); эта копия — независимая: свой компьютер, своя музыка,
свой ВДС, свой вкус. Общее с автором только канал обновлений (`https://vdsmusic.ru/soundflow/…`).

## Части и где они живут

| Часть | Где |
|---|---|
| Программа (сервер + окно) | `%LOCALAPPDATA%\Programs\SoundFlow\SoundFlow.exe` (Go + Wails, WebView2) |
| Качалка (Яндекс, musify, mp3party, торренты) | `%LOCALAPPDATA%\Programs\SoundFlow\downloader\` — свой Python в `python\`, код в `src\`, журнал `downloader.log`; программа запускает её сама |
| Модель звука, ffmpeg | рядом с exe: `onnxruntime.dll`, `cnn14.onnx(+.data)`, `ffmpeg.exe` |
| **Данные владельца** | `%LOCALAPPDATA%\SoundFlow\` — `soundflow.db` (каталог, лайки, SQLite), `settings.json`, `relay_key` (SSH-ключ канала), `blackbox\` (журналы телефона) |
| qBittorrent | `C:\Program Files\qBittorrent\`, настройки `%APPDATA%\qBittorrent\qBittorrent.ini`; Web UI 127.0.0.1:8080 |
| Автозапуск | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → `SoundFlow` |
| Телефон | приложение SoundFlow: свежий APK всегда по ссылке https://vdsmusic.ru/soundflow/apk/SoundFlow.apk; дальше обновление в самом приложении: Профиль → «Обновить» |
| ВДС | пользователь `soundflow-relay` (только проброс порта 127.0.0.1:8093), nginx-сайт `soundflow-remote`, сертификат Let's Encrypt |

Установщик и обновления **не трогают** `%LOCALAPPDATA%\SoundFlow\` — всё личное там.

## settings.json

Пишет мастер первого запуска. Переменные окружения, если заданы, главнее файла.

```json
{
  "musicDir": "D:\\Музыка",          // корень музыки; внутри «Яндекс» и «Торренты» — куда качается новое
  "yandexToken": "…",               // вход в Яндекс (не обязателен; нужен для вкуса по лайкам)
  "qbtUser": "soundflow",           // вход качалки в Web UI qBittorrent (ставит мастер)
  "qbtPass": "…",
  "addr": "",                       // пусто — порт по умолчанию 8090
  "relay": {                        // связь с телефоном вне дома через свой ВДС
    "host": "1.2.3.4:22", "user": "soundflow-relay", "secret": "…",
    "publicUrl": "https://1-2-3-4.sslip.io/soundflow-remote",
    "remoteBind": "", "keyFile": "", "hostKey": ""
  },
  "setupDone": true                 // мастер пройден (false/нет файла — мастер откроется снова)
}
```

Секреты (`yandexToken`, `qbtPass`, `relay.secret`, `relay_key`) — не показывать в чатах и не отправлять
никуда.

## Как это работает

- Мастер первого запуска: окно программы, страница `/setup/`. Шаги: папка музыки → Яндекс (можно
  пропустить) → торренты → свой ВДС → телефон. Повторно открыть: поставить `"setupDone": false`
  в settings.json и перезапустить программу.
- Скачивание: сначала бесплатные источники (musify → mp3party), Яндекс — последним и только с входом.
  Торренты — альбомами через qBittorrent (трекеры: nnmclub, rutor и др.).
- Вкус: лайки, дослушивания, пропуски, удаления с телефона. Если вошли в Яндекс — раз в 6 часов
  «Мне нравится» и песни своих плейлистов из Яндекса отмечаются лайками у песен, что уже есть
  в каталоге («Не рекомендовать» — в чёрный список). В аккаунт Яндекса ничего не пишется.
- Телефон дома ходит на `http://<IP компьютера>:8090`, вне дома — на `relay.publicUrl` с ключом
  `relay.secret` (оба телефон получает сам при подключении «Найти компьютер»).
- Канал вне дома: программа держит SSH-соединение к ВДС и просит его слушать 127.0.0.1:8093;
  nginx на ВДС отдаёт это наружу по https. Компьютер выключен — вне дома музыки нет (но скачанное
  на телефон играет офлайн).
- Обновления программы: раз в 6 часов она смотрит `https://vdsmusic.ru/soundflow/apk/pc-version.json`;
  есть новее — в окне кнопка «Обновить до …», установщик ставится тихо и перезапускает программу.

## Настройка ВДС

Команду показывает мастер (шаг «Музыка вне дома»); выполняется на ВДС от root:

```bash
curl -fsSL https://vdsmusic.ru/soundflow/apk/vds-setup.sh | sudo bash -s -- <ключ-base64> [домен]
```

Что делает скрипт: пользователь `soundflow-relay` с ключом программы (разрешён только проброс
127.0.0.1:8093, без консоли); nginx + certbot; адрес `https://<домен или ip-через-дефисы.sslip.io>/soundflow-remote/`.
Если на 443 уже работает nginx с разбором по имени сайта (stream + ssl_preread — так бывает с VPN
xray/3x-ui), он не забирает 443, а добавляет своё имя в этот разбор (upstream `soundflow_www`,
внутренний порт 127.0.0.1:7453). Перед правкой копирует `/etc/nginx` в `/root/soundflow-nginx-backup-*`,
при ошибке `nginx -t` возвращает всё как было. Настройки SSH-сервера не меняет.
Если 443 занят не nginx — ничего не меняет и сообщает об этом.

## Проверки и починка

- **Жива ли программа:** `http://127.0.0.1:8090/v1/health` → `{"status":"alive"}`.
- **Качалка:** `…\downloader\downloader.log`; программа поднимает её сама, после смены настроек
  перезапускает. Не качает — проверить интернет и что не забит диск.
- **qBittorrent:** в окне qBittorrent должен быть включён Web UI (Настройки → Веб-интерфейс, порт 8080,
  адрес 127.0.0.1). Вход — `qbtUser/qbtPass` из settings.json. Проверка из PowerShell:
  `Invoke-WebRequest -Method Post http://127.0.0.1:8080/api/v2/auth/login -Body @{username=…;password=…}`
  → код 200/204 — вход работает.
- **Телефон не находит компьютер дома:** один Wi-Fi; брандмауэр Windows должен разрешать SoundFlow
  (частная сеть); на компьютере нажать «Подключить телефон» (окно открыто 2 минуты), на телефоне —
  «Найти компьютер» (или Профиль → «Связь с домом» → адрес сервера → «Найти сервер самому»).
- **Вне дома не играет:** на ВДС `curl -s -o /dev/null -w "%{http_code}" https://<домен>/soundflow-remote/v1/health`
  → 403 значит канал жив (ключ не передан — так и должно быть), 502 — компьютер не подключён к ВДС
  (программа закрыта / нет интернета / ключ `relay_key` не совпадает с authorized_keys на ВДС).
  Журнал канала — в окне программы («Активность» / колокольчик).
- **Сертификат:** `certbot renew --dry-run` на ВДС; продлевается сам (certbot.timer).

## Правила для помощника

- Музыкальные файлы и `soundflow.db` — данные владельца: не удалять и не менять без его явного «да»;
  перед крупными правками — копия `%LOCALAPPDATA%\SoundFlow\`.
- Не ломать VPN на ВДС: перед правкой nginx — копия `/etc/nginx`, после — `nginx -t` и проверка, что
  VPN-порт и сайты отвечают.
- Не менять код программы: обновления приходят от автора; свои правки затрутся при обновлении.
  Проблема в самой программе — описать её автору (Alex) через владельца.
- Секреты из settings.json никуда не пересылать.
