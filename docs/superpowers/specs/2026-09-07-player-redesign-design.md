## Общее для любого варианта — «плеер из будущего»

**Движение (Flutter, без просадок):**
- Переход мини-плеер → полноэкранный: общий элемент (Hero) — обложка
  «вырастает» из мини-полосы; фон проявляется.
- Смена трека: обложка уезжает + новая приезжает (по направлению свайпа),
  цвет фона перетекает (`AnimatedContainer`/`lerp` 400 мс).
- Play/pause: перетекающая иконка (`AnimatedIcon`), лёгкий «отскок».
- Обложка «дышит»: чуть увеличивается на игре, уменьшается на паузе (как
  у Apple/One UI 8.5).
- Реакция вкуса: заливка + всплеск (`ScaleTransition`) + `HapticFeedback`.
- Прогресс тянется плавно (`AnimationController`, не тик раз в секунду).

**Фишки One UI 8.5 / последнего Android:**
- Динамический цвет из обложки (`palette_generator` или свой разбор), в
  духе Material You. У Alex Samsung — ложится в тему системы.
- Edge-to-edge, прозрачные системные полосы (Android 15+ обязательно).
- Предиктивный «назад» (Android 14+): свайп-назад корректно сворачивает
  плеер с превью.
- Богатый haptics на реакциях/переключении (`HapticFeedback.selectionClick`
  / `mediumImpact`).
- Медиа-уведомление / экран блокировки уже через `audio_service` — привести
  вид к Now Bar (обложка, живая позиция).

## Умный подбор по вкусу (пункт 11) — под капотом, одинаково для всех вариантов

### Новые события синка (`sync_events.kind`)
Сейчас: `play | like | unlike | delete | download`. Добавить:
- `dislike` — «убрать из Потока, файл не трогать, чуть снизить похожие».
- `undislike` — отмена (из настроек вкуса).
- `more_like` / `less_like` — «Больше/Меньше такого», слабее лайка, в
  Любимое не кладёт.
- `hide_artist` / `unhide_artist` — «не показывать этого исполнителя».
Причина у `dislike` не нужна (это чистый сигнал вкуса, в отличие от
`delete` с причиной).

### Сервер: таблица вкуса
Миграция `0006_taste.sql`:
```
taste_artist (artist_key text pk, score real, dislikes int, hidden bool,
              updated_at timestamptz)   -- агрегат по исполнителю
taste_track  (track_id text pk, signal text, at timestamptz)
              -- signal ∈ like|dislike|more|less, последний по треку
```
Наполняется в `handleSyncEvents` из новых kind. `hide_artist` →
`hidden = true`; несколько `dislike` одного исполнителя → `dislikes++`,
`score` вниз (не бан).

### Сервер: подбор очереди
`OrderBySimilarity` (или новый `OrderByTaste`) при сборке Потока/радио:
1. Кандидаты — как сейчас (id, что прислал телефон).
2. Базовый порядок — по звуковому сходству к seed (есть).
3. Поправки к позиции:
   - трек похож (по вектору) на `like`/`more` треки → выше;
   - похож на `dislike`/`less` → ниже;
   - `taste_artist.score` < 0 → весь исполнитель ниже (мягко, не убрать);
   - `taste_artist.hidden` → исключить из выдачи полностью;
   - недавно игранное → чуть ниже (разнообразие; раскидка по исполнителю
     уже есть).
4. `dislike` трека → он сам в Поток больше не попадает (как `blocked`, но
   файл на месте — отдельная метка, не `legacy_marks`).

### Телефон
- В плеере: строка реакции (👎/♥/👍) + свайп вниз на обложке = `dislike`
  текущего с переходом к следующему.
- Меню трека («ещё»): «Больше такого», «Меньше такого», «Не показывать
  этого исполнителя».
- Экран «Настройка вкуса» (в Профиле, рядом с «Сервер»): список скрытых
  исполнителей и тех, кого много дизлайкали, — вернуть. Список
  «дизлайкнутых треков» — вернуть в Поток.
- События копятся офлайн и уходят обычным синком (как play/like) — НИКАКИХ
  фоновых изолятов с sqflite (урок v16).

## Разбор внешнего дизайнера (Alex принёс, TG 18583–18585) — что принято

Принято:
- **Убрать ряд «меньше/нравится/больше» с экрана.** Лайк = двойной тап по
  обложке. «Меньше» — вывод из быстрого скипа (<10–15 c) + пункт в меню.
  «Скрыть исполнителя», «больше/меньше такого» — в меню по долгому нажатию.
- **Убрать двойной свайп-вниз.** Свайп вниз = только свернуть. Лайк —
  двойной тап.
- **Финальный набор жестов (без двойных свайпов):** тап = пауза; 2 тапа =
  лайк; свайп ←/→ = следующая/предыдущая (обложка едет за пальцем);
  свайп ↑ = очередь (упруго, текущий трек «привязан к пальцу»);
  свайп ↓ = свернуть; долгое нажатие = меню; тянуть по волне = перемотка;
  свайп по треку в очереди = убрать; тянуть трек = переставить.
- **Нижняя дуга большого пальца:** волна и кнопки — в нижней трети.
- **Волна:** тонкая визуально, зона касания на всю высоту (~52 dp);
  цвет из обложки; реагирует на воспроизведение; не DJ-инструмент.

  низкий контраст, лёгкий зум). Обложка — визуальный центр.
