  Она же слушает телефон по сети на порту 8091 (`/v1/*` для телефона, `/api/*` для окна; без пароля, в домашней сети).

  Вкладки окна: Каталог, Найти и скачать, Устройства, Вкус, Открытия, Настройки (+ скрытый «Журнал»).
- **Приложение на телефоне** (Android, Samsung SM-S936B): Flutter, `apps/mobile/lib` (~6 700 строк Dart). Три вкладки внизу
  (Поток / Моя музыка / Профиль), плеер, синхронизация с программой по Wi-Fi/USB, «убрать песню».
- **Качалка** (Python, Яндекс.Музыка/поиск/скачивание): живая копия `E:\soundflow-lab\fg-sidecar-src` (вне git),

- Правила проекта: `CLAUDE.md` (корень репозитория), `docs/RULES.md`; журнал этапов — `docs/PROGRESS.md` (длинный —

## Как оформлять отчёт (ваш файл — в этой же папке)

- По-русски, простым языком; технические слова — с короткой расшифровкой. Без воды.
- Каждый пункт: **что** · **где** (`файл:строка` или имя картинки) · **почему важно** (одной фразой для не-программиста) ·
  **что предлагаете** · **размер** (S — час, M — день, L — несколько дней) · **риск** · **приоритет** (P1 — сделать
  первым, P2, P3).
- Честно помечайте, что **проверено запуском/измерением**, а что — **по чтению кода**. Не выдумывайте: не уверены —
  так и пишите.
- В конце отчёта — «**Главное для Alex**»: 5 пунктов, каждый — одна короткая фраза простыми словами.
- Объём отчёта — до ~250 строк. Последнее сообщение вам вернуть мне коротким (до 15 строк): путь к файлу отчёта и
  «главное для Alex».
