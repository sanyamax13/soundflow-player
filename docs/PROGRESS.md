- `E:\soundflow` — этот репозиторий (создан 04.09.2026).
- `apps/mobile` — Flutter, только Android. Разработка и сборка APK на brain.

## Решения (04.09.2026, TG)

Дизайн «Афиша» один-в-один · сервер на Go сразу вместо старого, веб-фронт не нужен ·
только Android · на вход ничего (пароль один раз) · умный подбор по звуку — не в
первой версии, следующим шагом.

## Этапы (§9 плана)

- [x] **Этап 1 — каркас.** (коммиты `55ebdfe`, `8c49004`)
  - Flutter: 5 вкладок-заглушек (Поток/Чарты/Библиотека/Профиль/Настройки),
    тема «Афиша» (near-black + лайм #C6F000). APK собирается.
  - Go: `GET /v1/health` (+статус базы), `POST /v1/auth/login` → JWT-пропуск,
    Bearer-middleware, `GET /v1/me`, `GET /v1/tracks`, `GET /v1/music/{id}/file`
    (Range; без папки музыки отдаёт сгенерированный тон 440 Гц). Слушает tcp4.
  - Вход: пропуск в `flutter_secure_storage`. Старт приложения в сеть НЕ ходит —
    есть пропуск → сразу вкладки, в т.ч. офлайн.
  - PostgreSQL поднимается (docker compose), сервер к ней цепляется.
  - **Сквозной прогон на эмуляторе пройден:** первый запуск → вход; вход по
    паролю → 5 вкладок; Библиотека показывает трек с сервера; «Скачать» →
    файл 86 КБ в папке приложения; убил сервер → приложение открывается офлайн.
  - На реальном телефоне не проверялось.
- [ ] **Этап 2 — локальный плеер и скачанная музыка.** Go отдаёт файл, Flutter
  качает в кэш и играет офлайн (`just_audio`); мини-плеер; `downloaded_tracks`
  в SQLite.
- [ ] Этап 3 — синхронизация телефон↔сервер (`events_queue`, дедуп по uuid).
- [ ] Этап 4 — Поток (пакет 24ч). Этап 5 — Чарты. Этап 6 — Библиотека.
  Этап 7 — качество/версии. Этап 8 — админка. Этап 9 — полировка «Афиша».
