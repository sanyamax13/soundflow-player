SoundFlow — как ходят данные

Карта для быстрой ориентации: что откуда берётся, где напрямую, где через посредника. 28.09.2026.

Откуда берётся музыка
Бесплатные источники
musify.club, mp3party.net — ищутся первыми
Торренты
nnmclub, rutor и др. → qBittorrent (порт 8080)
Яндекс Музыка
последним; вход по токену. Плюс: лайки/плейлисты → вкус, «Волна», эталон длины
Качалка (Python)
↓ находит и качает
downloader (sidecar :8001)
audio_chain: musify→mp3party→Яндекс. Кладёт файлы в
G:\Музыка\Яндекс и \Торренты
↓ запускает и опрашивает
Сервер сам держит качалку
запускает процесс, отдаёт ей токен/пути через окружение
Сервер на ПК (Go)
SoundFlow.exe
окно (WebView2) + сервер в одном. Слушает :8090
Каталог + метки
SQLite soundflow.db
(%LocalAppData%\SoundFlow)
Музыка на диске
G:\Музыка — сами файлы (~120 ГБ)
«Хранители» (сами, фоном)
обложкинастроениебасформа волныгромкостьжанрвкус из Яндексасверка с диском
Связь с телефоном
Дома — напрямую Wi-Fi
телефон → http://IP-ПК:8090
быстро, без посредников
— или —
Вне дома — через ВДС SSH-канал
ПК держит SSH-туннель до ВДС → nginx → 127.0.0.1:8093 → сервер. Секретный ключ в заголовке. Телефон ходит на https://…/soundflow-remote
ВДС ещё отдаёт
канал обновлений: version.json + APK; для ПК pc-version.json + установщик
Телефон (Flutter)
↓ спрашивает по HTTP
Приложение
Поток, Моя музыка, плеер
Что берёт с сервера
/tracks каталог/cover обложка/audio файл/bass/waveform/search/sync события/blackbox лог/device/plan докачки
Что делает сам (офлайн)
радио/похожее по отпечаткам, темп полосы, косинусы вкуса — без сервера
■ синие — внешние сайты ■ жёлтые — ВДС (интернет) ■ лаймовые — сам SoundFlow Скачанное на телефоне играет локально; связь с сервером нужна для нового и для «вне дома».
