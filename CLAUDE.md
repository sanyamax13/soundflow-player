# Проект: SoundFlow

Личный офлайн-плеер одного человека.
Музыка: ~11 600 песен (~120 ГБ). Сервер дома + телефон Android + компьютер Windows.
Общие правила — в главном файле. Здесь только то, что касается плеера.

---

## Словарь владельца
Как владелец называет вещи (и как их может исказить расшифровка голоса):
- «мой плеер», «саунд флоу», «сон флоу» = SoundFlow
- «сервер» = домашний сервер с музыкой
- «ВДС» = сервер обновлений в интернете
- «Обновить» = кнопка в приложении на телефоне, откуда берётся новая версия
(Владелец дописывает сюда новые слова.)

---

## Дизайн
- Стиль: iOS 27 Liquid Glass + Samsung One UI 8.5.
- Тёмная тема, чистый чёрный, акцент лайм #B2FF00, шрифт Inter.

## Удобство экрана
- Меньше нажатий, управление одной рукой. Удобство важнее красоты.
- Кнопки не меньше 64pt.
- Меню из одного пункта не делать.
- Долгие нажатия не использовать — их не видно.
- Всё, что нужно нажимать, — в нижней половине экрана.
- Плашки сверху — только короткие и без кнопок.

## Что есть и чего нет
- Режима «машина» нет и не будет.
- Альбомы не нужны, только исполнители.
- Обложка — родная обложка песни. Обложка сборника — только если родной нет.

---

## Данные
- Удаление — насовсем, без корзины. Подтверждение в момент удаления.
- От 25 песен перед удалением программа сама сохраняет копию базы (каталог и метки, без самих файлов).
- Копию самой музыки (120 ГБ) не держим. Копируем только базу.
- Музыкальные файлы — только разовым скриптом, с копией и списком «что будет сделано».
- Каталог и метки вне скриптов не трогать.

---

## Технически
- Сервер: Go + SQLite, Linux, работает круглосуточно. Перед перезапуском — спросить.
- Телефон: Flutter, Android, Samsung S25. После правки — собрать новую версию и выложить в «Обновить».
- Компьютер: Windows, та же программа в режиме «только плеер».
- ВДС: канал обновлений и доступ по SSH.
