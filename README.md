# SoundFlow

Личный офлайн-плеер. Чистый проект: телефон на Flutter, сервер на Go.
Начат 04.09.2026 после ревизии переезда (старая веб-версия — в `e:\music-player`,
только как справочник).

```
apps/
  mobile/    — приложение (Flutter, только Android)
  server/    — сервер (Go): выдача музыки, Поток, чарты, синхронизация
docs/        — план переезда и продуктовые правила (перенесены из старого проекта)
docker-compose.yml — PostgreSQL для сервера (порт 5433)
```

## Запуск (разработка)

Сервер:
```
cd apps/server
copy ..\..\.env.example ..\..\.env   # заполнить пароль и ключ
go run ./cmd/soundflow-server         # слушает :8090
```
База (нужен Docker):
```
docker compose up -d
```

Приложение (адрес сервера по умолчанию — реальный fg в домашней сети,
т.к. собираем в основном для настоящего телефона):
```
cd apps/mobile
flutter run
```

Локальный сервер на этой машине / эмулятор — адрес нужно переопределить.
Эмулятор надёжнее достаёт сервер через проброс порта, а не через 10.0.2.2:
```
adb reverse tcp:8090 tcp:8090
flutter run --dart-define=SOUNDFLOW_API=http://127.0.0.1:8090
```
На реальном телефоне адрес по умолчанию уже LAN-адрес fg
(http://192.168.1.73:8090) — override нужен, только если он поменяется.
