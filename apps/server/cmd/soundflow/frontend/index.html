Найти и скачать

Ищем по Яндекс Музыке, затем musify и mp3party. Найденное сразу попадает в каталог и на телефон при синхронизации.
Опрашиваем трекеры (nnmclub, rutor, tapochek, rustorka). Отметь галочками нужные альбомы и нажми «Скачать выбранное» — качается через qBittorrent, песни идут в каталог.
qBittorrent не найден — он нужен для скачивания через торренты. Установи его и один раз включи Web UI в его настройках, или просто открой программу qBittorrent перед скачиванием.
