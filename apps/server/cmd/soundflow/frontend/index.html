Найти и скачать

Через тире: «Исполнитель — Название». Поиск идёт по Яндекс Музыке, затем musify и mp3party. Найденное сразу попадает в каталог и на телефон при синхронизации.
Опрос трекеров (nnmclub, rutor, tapochek, rustorka). Отметьте галочками нужные альбомы и нажмите «Скачать выбранное» — качается через qBittorrent, песни идут в каталог.
qBittorrent не найден — он нужен для скачивания через торренты. Установите его и включите Web UI в настройках, или просто откройте программу qBittorrent перед скачиванием.
