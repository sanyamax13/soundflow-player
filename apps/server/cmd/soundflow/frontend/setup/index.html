Где лежит музыка?

Выберите папку с музыкой. SoundFlow соберёт из неё каталог. Новые песни будут скачиваться сюда же — в папки «Яндекс» и «Торренты» внутри неё.

Торренты

SoundFlow сам находит и скачивает альбомы с торрентов через qBittorrent. Для этого ему нужен доступ к qBittorrent — нажмите «Включить».

Готово — теперь телефон

SoundFlow настроен. Каталог музыки собирается в фоне — это может занять время.

1. Наведите камеру телефона на код и установите приложение SoundFlow.

2. Откройте его и нажмите «Найти компьютер» (телефон — в том же Wi-Fi).
